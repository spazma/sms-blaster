Instrukcja: Automate + SMS Blaster

  1. Upewnij się, że telefon i PC są w tej samej sieci Wi‑Fi.
  2. W Automate utwórz nowy flow.
  3. Dodaj blok HTTP server:
    • metoda: GET
    • ścieżka: /webhook.*
    • port: taki sam jak w WEBHOOK_URL.
  4. Jako wynik bloku HTTP zapisz pełny URL w zmiennej, np. httpReqURL.
  5. Dodaj dwa bloki Variable set:
    • nr: urlDecode(replaceAll(httpReqURL, ".*[?&]nr=([^&]+).*", "$1"))
    • msg: urlDecode(replaceAll(httpReqURL, ".*[?&]msg=([^&]+).*", "$1"))
  6. Dodaj blok Send SMS without user interaction:
    • Number: nr
    • Message: msg
    • Subscription id: odpowiednia karta SIM.
  7. W tym pliku, w app.js, ustaw adres IP telefonu w stałej WEBHOOK_URL.
